# projeto-pratico
## Funcionalidade: Team Chat Interno

Sera implementado um chat interno para comunicacao entre os membros da equipe.
A funcionalidade permitira o envio de mensagens em tempo real, a criacao de
canais por assunto e o historico de conversas. O objetivo desse chat é fugir dos altos custos pagos no Slack.

## Versionamento Semântico

Convenção para numerar versões no formato `MAJOR.MINOR.PATCH` (ex.: `1.0.0`),
onde o número indica o tipo de mudança feita.

- **MAJOR**: incrementa em mudanças incompatíveis com a versão anterior.
- **MINOR**: incrementa em novas funcionalidades compatíveis.
- **PATCH**: incrementa em correções de bugs compatíveis.

Ao incrementar MAJOR, zera MINOR e PATCH. Ao incrementar MINOR, zera PATCH.
